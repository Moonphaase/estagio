Dataset Manager

Projeto de Estágio Curricular

O Dataset Manager é uma plataforma web desenvolvida no âmbito de um estágio curricular, com o objetivo de permitir a gestão, organização e partilha de datasets de forma simples e eficiente.

Django Django REST Framework PostgreSQL TailwindCSS Alpine.js

O que são datasets?

Um dataset (ou conjunto de dados) é uma coleção organizada de dados estruturados, geralmente guardados em formato de tabela (como ficheiros CSV ou Excel). Cada coluna representa uma variável específica e cada linha corresponde a um determinado registo. São o pilar fundamental para investigações científicas, análises estatísticas e treino de modelos de Inteligência Artificial.
