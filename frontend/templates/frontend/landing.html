Dataset Manager

Projeto de Estágio Curricular

O Dataset Manager é uma plataforma web desenvolvida no âmbito de um estágio curricular, com o objetivo de permitir a gestão, organização e partilha de datasets de forma simples e eficiente.

Django Django REST Framework PostgreSQL TailwindCSS Alpine.js
