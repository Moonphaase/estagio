Dataset Manager

Projeto de Estágio Curricular

O Dataset Manager é uma plataforma web robusta desenvolvida no âmbito de um estágio curricular. O ecossistema foi desenhado especificamente para simplificar o ciclo de vida dos dados, permitindo a gestão, organização e partilha segura de conjuntos de dados de forma simples e centralizada.

Características Principais

Gestão de Datasets

Crie, edite e organize os seus ficheiros num repositório unificado.

Partilha Controlada

Colabore com segurança através de permissões por utilizador.

Categorização

Agrupe conjuntos de dados por áreas de conhecimento.

Auditoria Completa

Monitorize logs de todas as alterações e downloads.

Controlo de Versões

Gerencie múltiplas iterações de um mesmo dataset.

Métricas & Estatísticas

Aceda a painéis visuais com contagens de acessos.

O que são datasets?

Um dataset é uma coleção organizada e estruturada de informações analíticas relacionadas. Geralmente, estes dados são apresentados de forma tabular com linhas e colunas (como um ficheiro .csv ou Excel), onde cada coluna define uma variável específica e cada linha mapeia um registo único.

Acesso à Plataforma

Como utilizador não autenticado, possui permissões de leitura para navegar, consultar estatísticas gerais e descarregar datasets **públicos**.
