Dataset Manager

Projeto de Estágio Curricular

O Dataset Manager é uma plataforma web desenvolvida no âmbito de um estágio curricular, com o objetivo de permitir a gestão, organização e partilha de datasets de forma simples e eficiente.

Características Principais

Gestão de Datasets

Criar, editar e organizar datasets com facilidade

Partilha Controlada

Partilhe datasets com permissões granulares

Categorização

Organize datasets por categorias personalizadas

Auditoria

Rastreie todas as operações e mudanças

Versioning

Gerencie múltiplas versões de datasets

Estatísticas

Visualize dados sobre downloads e acessos

Stack Tecnológico

Django Django REST Framework PostgreSQL TailwindCSS Alpine.js MinIO Railway

O que são datasets?

Um dataset (ou conjunto de dados) é uma coleção organizada e estruturada de informações relacionadas. Geralmente, estes dados são apresentados em formato de tabela com linhas e colunas (como um ficheiro CSV ou Excel), onde cada coluna define uma variável e cada linha representa um registo específico. São a base fundamental para análises estatísticas, relatórios e treino de modelos de inteligência artificial.

Acesso como Visitante

Como visitante, pode consultar datasets públicos, categorias e estas informações. Para criar e gerir os seus próprios datasets, faça login na sua conta.
